MTG Card Dividers

A collection of printable Magic: The Gathering card dividers designed to help organize and sort your collection.

The dividers are provided as ready-to-print files, making it easy to organize cards by set, color, type, or other categories.

📂 What's Included

This repository contains printable divider files for organizing MTG collections.

Each divider is designed to:

Fit neatly alongside standard MTG cards

Make collection organization quick and easy

Be easy to print and cut

Work well in card storage boxes, binders, and other storage solutions

Provide clear labels for quickly identifying different sections of a collection

🖨️ Printing

For best results:

Download the desired divider PDF.

Print at 100% / Actual Size.

Do not use "Fit to Page" or automatic scaling.

Print on cardstock or another sturdy paper for increased durability.

Cut along the provided guides.

Place the dividers in your card storage system.

Tip: Test-print one page before printing a large batch to make sure your printer is not applying any additional scaling.

📁 File Organization

Files are organized by category/set where possible.

Additional files and categories may be added over time.
